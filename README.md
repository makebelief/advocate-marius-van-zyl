# Advocate Marius van Zyl — independent website concept

Complete static nine-page website adapted from the *Abigail Ronald-Louw Attorneys* production reference. Preserves the established DM Sans/Manrope typography and 1200px container, accessible mobile nav and legal-site component design. HTML, CSS and vanilla JavaScript; no package installation needed.

## Preview
Run `python3 -m http.server 8000` in this folder and visit http://localhost:8000. Deploy to Vercel Framework **Other**, root/output `.`. `npx vercel --yes` creates a preview; `npx vercel --prod --yes` is for approved production publication.

## Pages
Home, About, Practice Areas, Our Attorney (labelled Our Advocate), Insights, Contact, Privacy, Terms, 404.
